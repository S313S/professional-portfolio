# 问题 #1: 左右文本组水平位置不对称

- **严重程度**: 🟡主要
- **类别**: 布局
- **问题层级**: 数值性（translate 偏移量需调整）
- **精度要求**: 近似即可
- **文件**: `src/components/WorksDetailSection.tsx`
- **代码位置**: 第 341 行和第 368 行

## 期望设计参考

![设计稿](../../character-battle-design-reference.jpeg)

设计稿中，"ON TRACK" 和 "OFF TRACK" 两组内容关于页面中轴线对称分布，左右距离中轴线大致相等（约 12.5% 视口宽度）。

## 根因分析

左列 `translate-x-[80px]` 和右列 `translate-x-[-20px]` 数值不对称，导致左组被过多地推向右侧（靠近中心），而右组偏移不足。

实测数据（viewport 1470px）：
- 视口中心: 735px
- 左组中心 X: 595px（距中心 140px）
- 右组中心 X: 935px（距中心 200px）
- 偏差: 60px

## 当前问题

左组距中轴线 140px，右组距中轴线 200px，60px 的不对称使得整体布局偏左。

## 修复指令

1. 打开 `src/components/WorksDetailSection.tsx`
2. 第 341 行，将左列的 `translate-x-[80px]` 改为 `translate-x-[50px]`
3. 第 368 行，将右列的 `translate-x-[-20px]` 改为 `translate-x-[-50px]`

这样两组各偏移 50px（方向相反），实现对称布局。

> 注：精确值可能需要微调。修改后在浏览器中确认视觉对称性。

## 策略提示

如果固定 translate 值在不同断点下不够灵活，考虑移除 translate，改用 grid 的 `justify-items` 或调整 `max-w` + `gap` 来实现对称。

## 验证方式

在浏览器中查看，两组文本应关于页面中轴线左右对称，视觉上间距均匀。可通过 DevTools 测量两组中心 X 坐标与视口中心的距离，差异应 < 10px。

## 不要修改

- 文字内容、字体大小、字重
- 按钮图标和样式
- 背景图和角色图像
- 描述文本的 font-size、line-height、color
- 整体 grid 结构（grid-cols-2）
