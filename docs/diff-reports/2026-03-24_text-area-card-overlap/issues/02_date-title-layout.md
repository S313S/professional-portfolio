# 问题 #2: 日期标题 "October 14th, 1894" 布局优化

- **严重程度**: 🟡主要
- **类别**: 排版 / 布局
- **问题层级**: 数值性（字号和定位需调整）
- **精度要求**: 近似即可（参照期望设计的比例和位置）
- **文件**: `src/components/CareerDetailSection.tsx`
- **代码位置**: 第 720-731 行（日期标题容器和 h2 元素）

## 根因分析

日期标题 "October 14th, 1894" 的字号过大，在当前视口下占据了过多的水平和垂直空间，与期望设计相比显得不够精致。

## 当前数值

| 元素 | 当前值 | 计算结果（1536px 视口） |
|------|--------|----------------------|
| h2 字号 | `text-[clamp(4.4rem,5vw,5.8rem)]` | 76.8px |
| h2 行高 | `leading-none` | 76.8px |
| h2 字间距 | `tracking-[-0.06em]` | -4.6px |
| 容器定位 | `absolute left-[35%] top-[2.5%]` | — |
| 容器宽度 | `w-[44%]` | 676px |
| 渲染尺寸 | — | 641 × 77px |

## 期望效果

> 期望设计参考图：`docs/diff-reports/careerDeatil_Demonstration.jpeg`

参照期望设计（参考图中红框区域）：
- 日期标题应更紧凑，字号适当缩小
- 标题与下方内容区域之间的比例更协调
- "LOCATION: LATITUDE 45.4215° N" 副标题与日期标题的间距合理

## 修复指令

调整 h2 的 clamp 字号范围，使日期标题在视觉上更精致：

```tsx
// 第 727 行
// 当前：
className="mt-3 font-serif text-[clamp(4.4rem,5vw,5.8rem)] leading-none tracking-[-0.06em] text-[#241b14]"

// 建议调整方向：
className="mt-3 font-serif text-[clamp(3.6rem,4.2vw,4.8rem)] leading-none tracking-[-0.06em] text-[#241b14]"
// 目标：约 60-65px（当前 77px），缩小约 15-20%
```

> 以上数值为建议方向。请在浏览器中对比期望设计，确认调整后的日期标题大小和位置与期望设计匹配。

## 策略提示

- 先调字号，观察效果后再决定是否需要调整容器的 `top` 或 `left` 定位
- 如果缩小字号后标题显得偏左/偏上，微调容器的 `left-[35%]` 和 `top-[2.5%]`
- 注意切换不同 record 时日期文字长度不同（"October 14th, 1894" vs "May 3rd, 1901"），确保都不溢出

## 验证方式

1. 运行 `npm run dev`，查看 CareerDetailSection
2. 确认 "October 14th, 1894" 的大小和位置与期望设计（第三张附图红框）接近
3. 切换不同 record，确认所有日期标题都正常显示且不溢出
4. 确认标题与下方 "CHRONICLE I:" 内容之间的间距合理

## 不要修改

- "LOCATION: LATITUDE 45.4215° N" 副标题的样式
- 三栏布局结构
- 文本内容区域（另一个 issue 处理）
- 右侧 aside 面板
- 标签页位置和交互
- 背景图片和色调
- 字体 family（保持 Playfair Display serif）
