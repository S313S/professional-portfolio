# 问题 #1: 标签页图片重影/重叠文字

- **严重程度**: 🔴严重
- **类别**: 布局
- **问题层级**: 结构性（可能是素材问题，也可能是 CSS 重复渲染）
- **精度要求**: 近似即可（消除重影即可，无需像素级对齐）
- **文件**: `src/components/CareerDetailSection.tsx`
- **代码位置**: 第 300-333 行

## 根因分析

需要先判断问题属于哪一层：
- **素材问题**：PNG 图片本身含有重叠文字图层 → 需重新生成干净图片
- **CSS 结构问题**：渲染循环产生了多余的 DOM 元素，或 z-index/opacity 导致多层透出

先检查素材（步骤 1），如果素材干净则是 CSS 结构问题（步骤 2）。不要跳过步骤 1 直接改 CSS。

## 期望效果

每个标签页是干净的单层撕纸卡片，图片清晰无叠影。

## 当前问题

标签页图片存在重叠幽灵文字（CREATIONS、EXPERIENCE、KNOWLEDGE），看起来像多层文字透出。可能是 PNG 素材本身含多图层，也可能是 CSS 导致重复渲染或 z-index 层叠。

涉及的图片资源：
- `/public/images/careerDetail_share_icon.png`
- `/public/images/careerDetail_career_icon.png`
- `/public/images/careerDetail_Industry knowledge_icon.png`

## 修复指令

分两步排查：

**步骤 1：检查 PNG 素材**

用图片编辑器打开上述 3 张 PNG，确认是否有重叠文字图层。如果 PNG 本身有问题，需要重新生成干净版本（无重叠文字层）。

**步骤 2：如果素材已替换但仍有重影，检查 CSS**

检查 `CareerDetailSection.tsx` 第 300-333 行，排查：
- 是否有多个 `<img>` 元素渲染同一图片（重复渲染）
- z-index 层叠导致多层可见
- `::before` / `::after` 伪元素产生额外图层
- opacity 设置导致底层内容透出

## 验证方式

- 目视检查每个标签页，确认只有一层干净文字，无幽灵/重影效果
- 分别点击每个标签页，确认切换后图片均无重叠

## 策略提示

- 先修结构性根因（素材或 CSS），再看效果
- 如果是素材问题：替换 PNG 后直接验证，不需要改代码
- 如果是 CSS 问题：关注渲染循环中是否有意外的多余 DOM 节点，不要通过增加 `overflow: hidden` 等 hack 来遮盖问题，而是消除根因
- 参考项目中已有的像素锁定方案（`CAREER_DETAIL_DESKTOP_TAB_PIXEL_RECTS`），标签页的定位算法已经比较完善，本次修复不需要动定位逻辑

## 不要修改

- 三栏布局结构（标签页 | 内容 | 面板）
- 背景图片和 #ece2d0 色调
- Playfair Display 衬线字体
- 标签页切换交互功能
- 滚动吸附行为
- 移动端响应式布局
- 标签页的整体位置和大小
- `CAREER_DETAIL_DESKTOP_TAB_PIXEL_RECTS` 定位参数（已校准，不要动）
- `getCoveredImageFrame` / `getDesktopTabStyle` 换算逻辑
