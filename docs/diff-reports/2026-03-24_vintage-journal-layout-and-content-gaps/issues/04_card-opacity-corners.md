# 问题 #4: 内容卡片透明度过高、圆角过大

- **严重程度**: 🟡主要
- **类别**: 颜色
- **文件**: `src/components/CareerDetailSection.tsx`
- **代码位置**: 第 370 行（主内容 article）

## 期望效果

内容卡片应呈现羊皮纸质感，接近不透明，搭配细腻复古边框和小圆角，营造档案卡片的感觉。

## 当前问题

卡片采用毛玻璃拟态风格：opacity 仅 0.58，圆角 1.5rem 过大，边框过淡（/14），整体显得现代而非复古。

## 修复指令

修改第 370 行主内容 `<article>` 元素的 className，替换以下三个值：

```
bg-[rgba(249,244,236,0.58)]  →  bg-[rgba(249,244,236,0.85)]
rounded-[1.5rem]             →  rounded-[0.4rem]
border-[#8f775f]/14          →  border-[#8f775f]/30
```

具体操作：在第 370 行找到 `<article>` 的 className 字符串，将上述三个 Tailwind 类逐一替换。其余类名保持不变。

## 验证方式

- 运行 `npm run dev`，确认主内容卡片：
  - 背景更不透明（能看到羊皮纸质感，底层背景图几乎不透出）
  - 圆角明显变小（接近直角）
  - 边框更明显（棕色细边框清晰可见）
- 与标注图 `annotated-diff.png` 对比确认风格接近

## 不要修改

- 三栏布局结构（标签页 | 内容 | 面板）
- 背景图片和 #ece2d0 色调
- Playfair Display 衬线字体
- 标签页切换交互功能
- 滚动吸附行为
- 移动端响应式布局
- 卡片内部的文字内容和排版
- 卡片的定位（position/top/left/width）
