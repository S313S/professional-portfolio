- **严重程度**: 🟡主要
- **类别**: 颜色

## 期望效果

辅助内容卡片（第二个 article）应与主内容卡片保持一致的羊皮纸质感：接近不透明背景、小圆角、清晰的复古边框。

## 当前问题

## 修复指令

```
bg-[rgba(250,246,240,0.62)]  →  bg-[rgba(250,246,240,0.88)]
rounded-[1.4rem]             →  rounded-[0.4rem]
border-[#8f775f]/14          →  border-[#8f775f]/30
```

具体操作：在第 388 行找到第二个 `<article>` 的 className 字符串，将上述三个 Tailwind 类逐一替换。其余类名保持不变。
